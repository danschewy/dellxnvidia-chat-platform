# Workspace conventions

- Put final user-facing work in `deliverables/`.
- Put temporary analysis in `working/`.
- Put reusable scripts in `scripts/` with a short header describing inputs and outputs.
- Never write secrets, tokens, passwords, or one-time codes into the workspace.
- Cite the source URL and retrieval date beside externally sourced business facts.
- Before replacing an existing deliverable, read it and preserve intentional structure.
